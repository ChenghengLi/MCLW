# Human Data Placeholder

Place your human-written text files here.

## Supported Formats

1. **Individual .txt files** - One text sample per file
2. **JSONL file** - Multiple samples in one file:
   ```json
   {"id": "human_001", "text": "Your human-written text here..."}
   {"id": "human_002", "text": "Another human-written sample..."}
   ```

## Tips

- Include diverse writing styles (formal, casual, academic, creative)
- Mix sentence lengths and structures
- Include some technical/formal writing (often falsely flagged by perplexity detectors)
